# SimpleUnlocker Next

Development-stage Windows 10/11 x64 recovery toolkit. This repository is being initialized with the Foundation source and Windows build workflow.

Based on the concept of [DesConnet's SimpleUnlocker](https://github.com/theDesConnet/SimpleUnlocker), GPL-2.0. This Foundation is independently written; the original application's source is not yet incorporated.

**Not production-ready.** Do not use on an infected production system. Read the Foundation README and VALIDATION.md once the source has been imported.
